# SMC Archiver

Windows용 멀티코어 압축 유틸리티입니다. Rust와 `egui`로 작성되었으며, 별도 설치 과정 없이 단일 실행 파일(`smc.exe`)로 동작합니다.

대용량 폴더나 개발 프로젝트를 백업할 때 단일 스레드 압축이 느리거나 이미 압축된 미디어 파일까지 다시 압축하느라 시간을 쓰는 문제를 줄이려고 자체 컨테이너 포맷(`.smc`)을 설계했습니다. 일상적인 용도로 쓸 수 있도록 표준 `.zip` 생성·해제와 `.7z` 열기·해제도 함께 지원합니다.

## 지원 포맷

| 포맷 | 압축 생성 | 열기 · 미리보기 · 해제 | 분할 볼륨 | 암호화 |
| :--- | :---: | :---: | :---: | :--- |
| `.smc` | O | O | `.smc`, `.s01`, `.s02`... | AES-256-GCM (데이터 + 파일 목록) |
| `.zip` | O | O | - | AES-256 (생성/해제), ZipCrypto (해제) |
| `.7z` | - | O | `.7z.001`, `.7z.002`... | AES-256 (해제) |

- `.zip` 해제는 Deflate, Deflate64, Zstd, LZMA, XZ, PPMd 방식을 지원합니다.
- `.7z` 해제는 LZMA, LZMA2, Zstd, LZ4, PPMd, Deflate, BCJ 필터를 지원합니다.

## 주요 특징

### 청크 단위 병렬 처리와 압축 생략
큰 파일은 `4 MB` 청크로 나누고, 작은 파일들은 배치 단위로 묶어 `rayon` 스레드 풀에서 병렬로 압축·해제합니다. 기본 모드(`SmartAuto`)에서는 `.mp4`, `.jpg`, `.png`, `.zip`, `.7z`, `.pdf` 등 이미 압축된 확장자는 재압축 없이 그대로 저장(`Store`)하고, 나머지 파일은 `Zstd (level 1)`로 압축해 본 뒤 크기 절감 폭이 2% 미만이면 원본 블록을 그대로 기록합니다. 필요에 따라 `LZ4`, `Zstd (level 3 / 9)`, `Store` 모드를 직접 고를 수도 있습니다.

### 개발 폴더 제외 옵션
프로젝트 폴더를 통째로 압축할 때 `node_modules`, `target`, `.git`, `.venv`, `__pycache__`, `.next`, `.gradle` 같은 의존성·캐시 디렉터리를 건너뛰는 옵션을 제공합니다. 포터블 프로그램이나 게임 폴더에서 실행 파일이 빠지지 않도록 `bin`, `dist`, `build`는 기본 제외 목록에 넣지 않았으며, 제외할 폴더 이름은 직접 추가·수정할 수 있습니다.

### 실사용 편의 기능
- **한글 파일명 복원**: `UTF-8`로 먼저 읽고, 실패하면 `CP949(EUC-KR)`로 폴백해 구형 압축 프로그램에서 만든 한글 파일명과 텍스트 미리보기가 깨지지 않도록 처리합니다.
- **알아서 풀기**: 아카이브 최상위에 단일 폴더만 있으면 하위 폴더가 이중으로 중첩되지 않게 풀고, 여러 파일이 섞여 있으면 아카이브 이름의 폴더를 만들어 정리합니다. 같은 이름이 이미 있으면 `폴더 (2)` 형태로 분리합니다.
- **내부 미리보기 및 바로 열기**: 전체 압축을 풀지 않고도 선택한 이미지·텍스트 파일을 메모리에서 바로 미리보거나 더블클릭해 실행할 수 있습니다. 임시 폴더(`%TEMP%\smc_instant_open`)에 풀린 파일은 12시간이 지나면 다음 실행 때 정리됩니다.
- **탐색기 연동 (무설치 레지스트리 등록)**: 관리자 권한이 필요 없는 현재 사용자 영역(`HKCU\Software\Classes`)에만 `.smc` 아이콘 연결과 우클릭 메뉴를 등록하거나 제거할 수 있습니다. `.zip`과 `.7z`는 기존 기본 연결 프로그램을 덮어쓰지 않고 우클릭 보조 메뉴만 추가합니다.

## 실행 및 사용법

[Releases](../../releases)에서 `smc.exe`를 받아 실행하면 GUI 창이 열립니다. 파일이나 폴더를 창에 드래그 앤 드롭해 바로 열거나 압축할 수 있으며, 커맨드라인 인자도 지원합니다.

```powershell
# GUI 실행
smc.exe

# 아카이브 열기 (.s01, .7z.002 같은 분할 볼륨 파일을 지정해도 첫 볼륨을 찾아 염)
smc.exe archive.smc

# 지정한 파일 또는 폴더를 바로 .smc로 압축
smc.exe --pack C:\work\my-project

# 지정한 아카이브를 바로 압축 해제
smc.exe --extract C:\downloads\bundle.7z
```

## `.smc` 컨테이너 구조 및 보안

```text
+-------------------------------------------------------------------+
| Header (32 B)                                                     |
|   Magic "SMC\x01" (4B) | Flags (4B) | Salt (16B) | IndexPos (8B)  |
+-------------------------------------------------------------------+
| Chunk Stream                                                      |
|   [Chunk 0] [Chunk 1] ... (Store / LZ4 / Zstd, 선택적 AES-GCM)    |
+-------------------------------------------------------------------+
| Footer Index                                                      |
|   CompLen (8B) | RawLen (8B) | Zstd(JSON Index) | Magic "SMCE"    |
+-------------------------------------------------------------------+
```

- **암호화**: 비밀번호를 설정하면 16바이트 랜덤 솔트와 `PBKDF2-HMAC-SHA256`(600,000회 반복, 구버전 `v1.1` 60,000회 호환)으로 256비트 키를 파생합니다. 각 데이터 청크와 파일 목록(Footer Index) 모두 블록 번호 기반 고유 논스를 사용하는 `AES-256-GCM`으로 암호화되어, 비밀번호 없이는 내부 파일 목록도 볼 수 없습니다. 메모리에 캐시된 키는 해제(`Drop`)될 때 `write_volatile`로 0으로 덮어씁니다.
- **무결성 및 경로 검증**: 디스크에 파일을 풀지 않고 모든 청크의 복호화 태그와 원본 파일 단위 `CRC32`를 병렬로 대조하는 무결성 검사를 지원합니다. 압축 해제 시에는 `..` 상위 경로 이동(Zip-Slip), 드라이브 문자, NTFS 대체 데이터 스트림(`:`)이 포함된 경로를 차단합니다.

## 빌드 방법

### 요구 사항
- Windows 10 / 11 (x64)
- Rust 1.80 이상 (MSVC 툴체인)

### 빌드 및 테스트
```powershell
# 테스트 실행
cargo test

# 릴리즈 바이너리 빌드 (target\release\smc.exe)
cargo build --release
```

## 디렉터리 구조

```text
├── Cargo.toml
├── build.rs                # 실행 파일 아이콘(.ico) 및 Windows 리소스 임베딩
└── src/
    ├── main.rs             # 엔트리포인트, CLI 인자 처리, 통합 테스트
    ├── format.rs           # .smc 헤더/인덱스 포맷 정의 및 확장자·경로 필터 규칙
    ├── archiver.rs         # .smc 병렬 압축/해제, 분할 볼륨 I/O, 무결성 검사
    ├── external_archive.rs # .zip / .7z 리더·병렬 해제 및 .zip 생성
    ├── crypto.rs           # PBKDF2 키 파생 및 AES-256-GCM 블록 암복호화
    ├── gui.rs              # egui / eframe 기반 GUI
    ├── explorer.rs         # HKCU 레지스트리 기반 탐색기 파일 연결 및 우클릭 메뉴
    └── icon.rs             # 윈도우 아이콘 생성
```
